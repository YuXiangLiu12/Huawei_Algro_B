# Q1 标定与数值验证

## 本次修订：局部液态水—冰相变

借鉴三相水迁移、局部成核与潜热反馈的思路，启用已有的过冷液态水分支，
保留五层 MEA 及两侧板材的七层计算域、局部冰阻塞反馈和守恒离散。
实验标定目标仍然只有附件中的电压和温度；其他模型的起冰时间、冰峰值只用于对比。

```matlab
% 最简单的方式：在 MATLAB 中打开项目根目录的 run_q1.m，点击运行。
% 或先将 q1 源码目录加入搜索路径，然后：
out = q1_main([],'revised');
% 已有修订版参数时，仅重新验证：
% out = q1_main([],'revised_resume');
```

入口按源码位置解析根目录，不依赖 `pwd`；`root` 也可显式传项目根目录或
`q1` 子目录。标定与验证始终重新读取当前项目的 `附件2.xlsx`，不复用旧 MAT
文件里保存的观测数据。优化输出和检查点统一写入当前项目的 `results/q1_v06`。

`revised` 会跳过已正常停止的标定；未完成者从保存参数续算，每个阶段每次
最多 300 次目标函数评估。检查点只恢复参数，不恢复优化器内部状态。
`revised_resume` 要求五参数和六参数的 `fit_*.mat` 均已存在，然后重做数值验证。
需要强制增加某阶段迭代预算时调用 `q1_revise([],'phase',600)`，五参数阶段用
`'transport'`。不要同时启动两个写入同一阶段检查点的 MATLAB 进程。

完整流程在同一细网格上比较原直接结冰、局部五参数和局部六参数方案，
不再依赖缺失的 `q1_v05/verification_direct` 目录。输出包括：

- `model_comparison.csv` 与 `修订结果说明.md`：实际 RMSE、两套权重 SSE、参数数量和数值检查结论。
- `verification_transport`、`verification_phase`：粗中细网格、时间精度检查、参数边界和优化历史。
- 候选方案验证目录中的 `phase_assumption_sensitivity.csv`：成核阈值与冻结速率敏感性。

模型选择优先要求优化正常停止并通过数值检查；两者均满足时，六参数方案
需降低至少 5% 的细网格新权重 SSE 才选用。这是工作阈值，不是显著性检验。
若均不合格，报告只标记候选方案。参考流程图没有可核实的数值指标，代码
不再输出来源未核实的硬编码参考 RMSE 或冰量。

修订流程先标定五个电化学与输运参数，再加入束缚水向液态水转化速率 `kbl`，
其工作边界为 0.02～5 s⁻¹。液态水成核阈值 0.03 和冻结速率 1 s⁻¹ 为假设，
在最终结果上另做敏感性试算，不从其他模型的冰量结果反求。

修订版残差尺度为 0.02 V、0.1 ℃，用于提高温度拟合在目标函数中的权重，
不是实验测量不确定度。输出同时提供旧尺度 0.02 V、0.5 ℃ 下的 `weighted_SSE`
及实际标定尺度下的 `calibration_SSE`，不同权重下的目标值不能直接比较。
修订版文件单独保存在 `results/q1_v06`，原直接结冰模型保留在 `results/q1_v05`。

## 原直接结冰模型

项目根目录为 `q1` 文件夹的上一级，`附件2.xlsx` 直接放在根目录。
函数默认根据源码所在位置确定根目录，不依赖 MATLAB 的当前工作目录。

在项目根目录运行：

```matlab
addpath(fullfile(pwd,'q1'));
q1_checks();
```

直接结冰模型的实际调用方式：

```matlab
root = pwd;
fit = q1_fit_transport(root, 'direct', 600);
report = q1_verify_transport(root, 'direct');
```

联合标定两种温度的电压与温度数据，共用五个参数：−20 ℃参考交换电流、
活化能、催化层电导率系数、动力学含水量指数、束缚水扩散倍率。
目标函数为 `sum((电压误差/0.02 V).^2) + sum((温度误差/0.5 K).^2)`，
包含两组各 184 个时刻的数据；该值是加权残差平方和，不是 RMSE。

标定结果保存在 `results/q1_v05/fit_transport_direct.mat`，每轮优化参数保存在
同目录的 `checkpoint_transport_direct.mat`。重新调用标定函数时优先读取已保存
的完整结果，否则从检查点参数开始新的优化过程；这不是恢复优化器内部状态。

`q1_verify_transport` 不需要旧版本结果或源码备份。它固定标定参数，依次运行
粗、中、细网格，再在细网格上收紧时间积分精度。结果保存在
`results/q1_v05/verification_direct`：

- `grid_summary.csv`：每组数据在各网格上的加权误差、RMSE、含水量和守恒误差。
- `numerical_checks.csv`：相邻网格和时间精度变化造成的最大轨迹差异。
- `fitted_parameters.csv`：参数值、边界及是否接近边界。
- `optimization_history.csv`：本次优化的迭代记录。
- `verification_report.md`：优化停止原因及数值检查结论。
- `mesh_comparison.png`：两种温度下的网格对比图。
- `coarse`、`medium`、`fine`：各网格的完整轨迹、参数和图表。

数值检查的预设目标为：最大电压差不超过 5 mV，最大温度差不超过 0.05 K，
最大冰体积分数差不超过 0.005。它们是本次采用的数值精度目标，不是实验不确定度。
若中、细网格差异超限，就不能声称网格独立；应进一步加密并考虑在细网格重新标定。
优化器正常停止仅表示满足局部停止条件，不代表已找到全局最优解。
电压、温度均为训练数据误差；冰量缺少实验观测，仅为模型预测。

原有 `q1_main` 是包含其他模型分支的完整流程，其最终历史比较还依赖旧版本
结果及 `source_before` 备份。仅验证当前直接结冰模型时使用上述独立入口。
